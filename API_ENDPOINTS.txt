Tutoring Manager - API Endpoints
Base path: none (no /api prefix)

Students
GET /students?userId={userId}&page={page}&size={size} - List a user's students.
GET /students/{id} - Get one student by ID.
POST /students - Create a new student.
PUT /students/{id} - Update an existing student.
DELETE /students/{id} - Delete a student.

Tutoring classes
GET /tutoring-classes?userId={userId}&page={page}&size={size} - List a user's classes.
GET /tutoring-classes/{id} - Get one class by ID.
POST /tutoring-classes - Create a new class.
PUT /tutoring-classes/{id} - Update an existing class.
DELETE /tutoring-classes/{id} - Delete a class.

Enrollments
GET /enrollments?page={page}&size={size} - List enrollments.
GET /enrollments/{id} - Get one enrollment by ID.
POST /enrollments - Enroll a student in a class.
PUT /enrollments/{id} - Update an enrollment.
PATCH /enrollments/{id}/status?status={status} - Change enrollment status.
DELETE /enrollments/{id} - Remove an enrollment.

Tutoring sessions
GET /tutoring-sessions?page={page}&size={size} - List sessions.
GET /tutoring-sessions/{id} - Get one tutoring session by ID.
POST /tutoring-sessions - Schedule a new tutoring session.
PUT /tutoring-sessions/{id} - Update session details.
DELETE /tutoring-sessions/{id} - Delete a tutoring session.

Payments
GET /payments?userId={userId}&page={page}&size={size} - List a user's payments.
GET /payments/{id} - Get one payment by ID.
POST /payments - Create a payment record.
PUT /payments/{id} - Update a payment record.
DELETE /payments/{id} - Delete a payment record.

Notes
The payment/session attach-detach endpoints shown in older docs are not implemented in the current controllers.
